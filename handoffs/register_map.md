# AXI-Lite Register Map

Generated by agent: pynq_ecg_gen
Milestone: 1

---

## Base Address

```
0x43C00000
```

This base address is assigned in the Vivado Block Design AXI interconnect.
The AXI-Lite slave (32-bit data bus, 32-bit address) is implemented by the
`pynq_ecg_process` agent and exposes all registers below.

### BPM Range and Reload Formula

```
sample_rate  = bpm * 6   (samples/sec — 360 samples × bpm/60 Hz)
base_reload  = 100_000_000 / (bpm * 6) - 1

Min BPM = 30  → base_reload = 555554
Max BPM = 240 → base_reload = 69443
```

## Notes

1. Bits [31:8] of each generation register are reserved and should read as 0.
2. Writing a BPM value outside 30–240 is not hardware-enforced; the PS software
   driver must clamp values before writing.
3. RR_FLUCT=0 and AMP_FLUCT=0 produce a perfectly periodic, fixed-amplitude
   output. Increase these values to add realism for HRV demonstrations.
4. All registers are writable from PS user-space via `/dev/mem` or the PYNQ
   overlay `mmio` interface at base address 0x43C00000.
5. The AXI-Lite slave must support byte-enable writes; unused upper bytes must
   not corrupt lower byte register contents.
