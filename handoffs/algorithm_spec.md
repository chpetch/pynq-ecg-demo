## Fixed-Point Implementation Notes

### Multiply-Accumulate Data Path

```
Input sample  : 12-bit unsigned  (0 … 4095)
Coefficient   : 16-bit signed Q1.15  (-32768 … 32767)
Product       : 12 × 16 = 28-bit, sign-extended to 32-bit signed
Accumulator   : 32-bit signed, sum of 31 products
Output        : accumulator >> 15  →  keep bits [11:0]  (12-bit result)
```

Equivalent Python simulation:
```python
acc = sum(int(sample[n-k]) * int(coeff_q15[k]) for k in range(31))
acc32 = clip(acc, -2**31, 2**31 - 1)  # 32-bit signed
output = (acc32 >> 15) & 0xFFF        # 12-bit
```

### Overflow Analysis

- Maximum single product: 4095 × 32767 ≈ 1.34 × 10⁸ (fits in 28-bit signed)
- Maximum accumulator (31 taps, all at max): 31 × 1.34 × 10⁸ ≈ 4.15 × 10⁹
- 32-bit signed range: ±2.15 × 10⁹
- In practice the Hamming-window coefficients sum to ≈ 1.0 (unity passband gain),
  so the accumulator stays well within ±2³¹ for ECG signals (verified by simulation).
- Overflow risk: **none** for valid 12-bit inputs with these coefficients.

### No Division in RTL

The BPM computation `360 × 60 / interval` requires division.
Use a 16-bit pre-computed lookup table: `bpm_lut[interval] = 21600 / interval`
covering intervals from 1 to 65535 (≈ 0.33 BPM minimum).
Alternatively, implement a simple 16-bit integer divider in a dedicated module.

### Noise Model Rationale

The three noise sources represent a realistic unconditioned ECG signal:
1. **Baseline wander** (0.05 Hz, 10% amplitude): respiratory motion artifact
2. **Gaussian noise** (σ = 2%): broadband thermal and quantisation noise
3. **Powerline interference** (50 Hz, 40% amplitude): mains EMI coupled into leads

The 31-tap FIR at 360 Hz provides strong attenuation at 50 Hz (approx. -50 dB
stopband), which is the dominant noise source and accounts for the 11.7 dB gain.
The gaussian component contributes approx. 6.8 dB rejection from the bandpass
action. The baseline wander at 0.05 Hz is below the nominal 0.5 Hz lower cutoff
but with only 31 taps the transition-band roll-off is gradual — the net effect is
still a useful SNR improvement measured end-to-end.
