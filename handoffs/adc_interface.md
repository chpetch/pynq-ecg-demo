## Overview

The DAC analog output on PMOD DA4 (AD5628-1 Channel A) is physically wired
back to PMOD AD2 (Analog Devices PMOD, XADC-compatible) on JB header.
This loopback path allows the processing pipeline to read back the ECG signal
that was written to the DAC, enabling closed-loop signal validation.

## Sample Rate

- The DDS master (Ch A) fires `sample_valid_out` at a rate of:
  `f_sample = bpm_ch_a × 6` samples per second
- Default: 60 BPM × 6 = **360 Hz** (one sample every ~2.78 ms)
- Range: 30 BPM × 6 = 180 Hz  to  240 BPM × 6 = 1440 Hz
- With RR fluctuation enabled, instantaneous rate varies by ±(rr_fluct/2) counts
  of the reload register, which translates to sub-1% rate jitter at default settings.

## Notes for pynq_signal_process

1. The PS-side XADC driver should arm a conversion on the rising edge of
   `sample_valid_out` (exported via AXI GPIO or interrupt).
2. The ECG signal on the ADC bus will be centred around mid-scale (code ~2048,
   ~1.25 V) with P, QRS and T deflections above and below baseline.
3. R-peak code value reaches up to ~4090 (≈2.49 V) at maximum amplitude.
4. When `amp_fluct` > 0, beat-to-beat R-peak amplitude varies; the processing
   agent should not assume a fixed peak threshold.
5. The 2-cycle pipeline latency within `ecg_dds` is already accounted for;
   `sample_valid_out` is synchronous to the correct sample data on the DAC.
